# Fretwise

Learn the theory inside your guitar tabs. Paste a tab (or grab one from a tab website with
the "→ Fretwise" bookmark button) and Fretwise finds its key and chords, writes them as
numerals and colors every note by its scale degree.

**Try it:** https://b-hilprecht.github.io/fretwise-app/

Everything runs in your browser. Imported tabs are saved only in your browser's storage;
nothing is uploaded anywhere.

This repository only holds the published site. It is generated, so please don't edit it by hand.
